- Detect the workspace tooling and package manager from files like `package.json`, `bunfig.toml`, `vite.config.ts`, and project scripts.
- If the user provides a specific command, run that command directly.
- If no command is provided, choose the most likely non-destructive run target: app startup script, local dev server, or test command.
- Confirm before running any destructive or environment-changing commands.
- Return the command execution result clearly and concisely.

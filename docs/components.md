# Component Catalogue

All shared components live under `src/components/`. UI primitives from shadcn/ui live in `src/components/ui/`.

---

## Public Site Components

### `SiteShell`

Wraps every public-facing page with consistent padding, max-width container, and spacing between sections.

```tsx
<SiteShell>
  <Hero />
  <ServiceDomains />
  <CtaBanner />
</SiteShell>
```

### `Navbar`

Top navigation bar for the public site. Contains the SDS logo and links to all public pages. Renders a mobile hamburger menu on small screens.

**Links configured in:** `src/components/Navbar.tsx` → `links` array

### `Footer`

Site-wide footer with company description, navigation columns (Company, Services), and social/contact info.

### `Hero`

Full-width hero section used on the home page. Accepts a headline, subheadline, and CTA buttons.

### `PageHero`

Lightweight hero banner used at the top of inner pages (About, Services, Careers, etc.). Displays a page title and optional subtitle against a dark/gradient background.

### `ServiceDomains`

Grid of service domain cards shown on the home page. Each card has an icon, title, and description.

### `CtaBanner`

Full-width call-to-action strip. Used at the bottom of pages to prompt users to get in touch.

---

## Portal Components

### `InternalPortalNav`

Shared sidebar/topbar navigation component rendered inside all portal layouts (`admin.tsx`, `client.tsx`, `employer.tsx`, `employee.tsx`). Highlights the active route.

### `PortalBanner`

Page-level header rendered at the top of each portal sub-page. Shows the page title and optional breadcrumb.

## Adding a New Component

1. For a **shadcn/ui component** not yet installed:
   ```bash
   npx shadcn@latest add <component-name>
   ```
2. For a **custom component**, create it under `src/components/YourComponent.tsx` and export a named function component.
3. Import using the `@/components/` alias (configured in `tsconfig.json` and `vite.config.ts`).

# Route Reference

TanStack Router uses **file-based routing**. Every `.tsx` file in `src/routes/` maps directly to a URL.

> `routeTree.gen.ts` is auto-generated by the Vite plugin on every dev/build run. Do **not** edit it manually.

---

## File → URL Mapping Rules

| File                      | URL                           |
| ------------------------- | ----------------------------- |
| `index.tsx`               | `/`                           |
| `about.tsx`               | `/about`                      |
| `services.tsx`            | `/services`                   |
| `careers.tsx`             | `/careers`                    |
| `contact.tsx`             | `/contact`                    |
| `admin.tsx`               | `/admin` (layout)             |
| `admin.timesheets.tsx`    | `/admin/timesheets`           |
| `admin.employees.tsx`     | `/admin/employees`            |
| `admin.employees.$id.tsx` | `/admin/employees/:id`        |
| `admin.jobs.tsx`          | `/admin/jobs`                 |
| `admin.reports.tsx`       | `/admin/reports`              |
| `client.tsx`              | `/client` (layout)            |
| `client.timesheets.tsx`   | `/client/timesheets`          |
| `client.invoices.tsx`     | `/client/invoices`            |
| `client.resources.tsx`    | `/client/resources`           |
| `client.requirements.tsx` | `/client/requirements`        |
| `employer.tsx`            | `/employer` (layout)          |
| `employer.timesheets.tsx` | `/employer/timesheets`        |
| `employer.candidates.tsx` | `/employer/candidates`        |
| `employer.jobs.tsx`       | `/employer/jobs`              |
| `employer.reports.tsx`    | `/employer/reports`           |
| `employee.tsx`            | `/employee`                   |
| `__root.tsx`              | App shell (wraps every route) |

---

## Special Files

| File                    | Purpose                                                                                                                          |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `__root.tsx`            | Global layout — renders `<Outlet />` for all routes. Contains `<Navbar>`, `<Footer>`, toast providers, and global `<head>` tags. |
| `_layout.tsx` (pattern) | Nested layout — renders children via `<Outlet />` without appearing in the URL.                                                  |
| `$param.tsx` (pattern)  | Dynamic segment — param available via `useParams()`.                                                                             |

---

## Adding a New Route

1. Create a new file under `src/routes/`, e.g. `src/routes/team.tsx`
2. Export a `Route` using `createFileRoute`:

```tsx
import { createFileRoute } from "@tanstack/react-router";

export const Route = createFileRoute("/team")({
  component: TeamPage,
});

function TeamPage() {
  return <div>Team</div>;
}
```

3. The Vite plugin auto-updates `routeTree.gen.ts` on save.
4. If you want the page in the nav, add it to `src/components/Navbar.tsx` and `src/components/Footer.tsx`.

## Navigation Component

Public nav links are defined in `src/components/Navbar.tsx`:

```ts
const links = [
  { to: "/", label: "Home" },
  { to: "/services", label: "Services" },
  { to: "/about", label: "About" },
  { to: "/careers", label: "Careers" },
  { to: "/contact", label: "Contact" },
];
```

Portal navigation (Admin, Client, Employer, Employee) uses the `InternalPortalNav` component rendered inside each portal layout route (`admin.tsx`, `client.tsx`, etc.).

## SEO Per Route

Each route's `head()` export sets the page `<title>` and meta description:

```ts
export const Route = createFileRoute("/services")({
  head: () => ({
    meta: buildSeoMeta({
      title: "Services | SDS Consulting",
      description: "...",
      path: "/services",
    }),
  }),
  component: ServicesPage,
});
```

See `src/lib/seo.ts` for the `buildSeoMeta()` implementation.

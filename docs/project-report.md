# Project Report

Last updated: July 9, 2026

## Project Summary

SDS AI Core is a full-stack SSR web application for SDS Consulting Services. It combines a public marketing website with role-based operational portals for AI data center staffing, workforce management, timesheets, leave requests, client requirements, job postings, and reporting.

The application is built as a TanStack Start app with file-based routing, server functions, Supabase-backed data access, and a Tailwind/Radix component system.

## Business Scope

SDS Consulting Services provides staffing and infrastructure support for AI-driven data centers. The platform supports:

- Public discovery of SDS services, careers, and contact information
- Client-facing requirement submission and resource access
- Employer-facing job, candidate, timesheet, and reporting workflows
- Employee-facing profile, document, leave, and timesheet workflows
- Admin-facing employee, job, leave, timesheet, activity, and report management

## Backend And Data

The app uses Supabase for persisted data and role-aware backend operations. Server-side logic lives in `src/lib/api/` as TanStack Start server functions. Supabase schema migrations live in `supabase/migrations/`.

Major backend areas include:

- Employee records and employee identity
- Job and requirement management
- Timesheet foundation and approval workflow
- Leave management
- Notifications
- Audit logging
- Portal role policies

## Security Model

The app separates public routes from authenticated portal routes. Role routing and route access are handled in:

- `src/lib/auth-roles.ts`
- `src/lib/route-access.ts`
- `src/components/AuthRouteGate.tsx`

Server-only Supabase access uses non-`VITE_` environment variables and must remain outside the browser bundle.

- The production build reports a large client chunk warning. Future optimization can introduce additional route-level or library-level code splitting.
- `src/routeTree.gen.ts` is generated by TanStack Router and should not be edited manually.
